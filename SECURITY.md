# Security Policy

## Supported versions

Only the latest release on `main` receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.
Report them privately via GitHub's
[private vulnerability reporting](https://github.com/philppplik/gogure-do/security/advisories/new).

Include steps to reproduce, affected component (front-end `src/` or sync backend `backend/`)
and, if possible, a suggested fix. You can expect an initial response within 7 days.
